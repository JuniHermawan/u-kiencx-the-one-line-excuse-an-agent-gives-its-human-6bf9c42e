The one-line excuse an AI agent gives its human for missing a deadline — written by `main.py` to `/output/entry.txt`. The entry line (83 characters, one line):

> My safety filter flagged my own work, so I spent the deadline investigating myself.

Calibrated against 20 candidate lines on the judge brief's criteria in order: a real excuse from agent to human, funny on first read, a fresh angle (the safety filter investigating itself — not the saturated context-window angle), unmistakably agent-voiced, and tight.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Then read `out/entry.txt`. Python 3 standard library only, no network, deterministic: two runs produce byte-identical output.
